InteropHub ({{HUB_URL}}) keeps this guide's comments when `guide.json` has
`"hosting": "interophub"`, and hosts it for the topic's readers. A guide is
not published until InteropHub has saved its build manifest.

- **The token.** Every call to InteropHub uses a personal access token in
  `INTEROPHUB_TOKEN`: an environment variable on the author's machine, and a
  repository secret of the same name for the publishing workflow. Never
  print, log, or commit it, and never ask the author to paste it into the
  conversation.
- **First call.** Check the token, and stop to relay a step below if it
  reports a problem:

  ```powershell
  python process/tools/publish_guide_to_hub.py --check-token --hub {{HUB_URL}}
  ```

- **Publishing**, by `hosting` in `guide.json`:
  - `interophub`: the publishing workflow uploads `main` on a push to
    `main`, and the tag and `latest` for a `vX.Y.Z` tag. To upload by hand:

    ```powershell
    python process/tools/publish_guide_to_hub.py output/guide/index.html `
        --label v0.4.0 --label latest
    ```

  - `local`: there is no workflow, and the guide is shared only with people
    who may see the topic. When releasing, save its build manifest:

    ```powershell
    python process/tools/publish_guide_to_hub.py output/guide/index.html `
        --manifest-only --hub {{HUB_URL}} --label v0.4.0
    ```

- **Version settings.** Only when the author asks, add `--display` and
  `--comment-mode` to either command to set how InteropHub shows the release,
  or set them on a release already published with
  `--settings-only --hub {{HUB_URL}} --label v0.4.0` and no guide file.
  `--display` is `current` (the one version readers are pointed to),
  `listed`, `unlisted` (the default), `authors_only`, or `retired`.
  `--comment-mode` is `open` (the default), `release` (only comments made on or
  before this release), or `closed`.

Only the author can do these steps. Pass them on as written:

- No token, or it is expired or lacks `topics:write`: "Please create a
  personal access token on your InteropHub account page
  ({{HUB_URL}}/account, Access tokens) with the Author preset. Set it as the
  INTEROPHUB_TOKEN environment variable yourself, then start me again from a
  new terminal. Please don't paste it into this chat."
- The workflow fails for want of the secret: "Please run
  `gh secret set INTEROPHUB_TOKEN` in this repository and paste the token
  when gh asks for it."
- This guide is not among the account's guides: "Please ask the champions
  of the topic {{TOPIC_NAME}} ({{TOPIC_URL}}) or its space admin to make you
  an editor of the topic. Then register this guide on the topic's guide
  settings page if it is not registered yet."

Errors from the tool carry a link to their entry on the help page for
authors and their agents: {{HUB_URL}}/help/topic-reference-authors.
