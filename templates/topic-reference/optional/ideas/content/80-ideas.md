# Appendix: Ideas

This appendix records ideas worth considering, each with its source. An idea
is not a recommendation or a decision. When one is sorted, it is written into a
chapter, a working decision, or an open question, and its row links there.
Rows are never deleted, so comments on them stay attached.

Status is **Open** (not yet sorted), **Sorted** (written into the document,
with a link to where), or **Set aside** (not used, with the reason).
